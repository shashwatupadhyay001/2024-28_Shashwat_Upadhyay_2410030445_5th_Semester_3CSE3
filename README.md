## 📌 About the Internship

The internship focused on building a strong practical foundation in full-stack web development — progressing from front-end fundamentals (HTML, CSS, Bootstrap, JavaScript/jQuery) to back-end and enterprise Java technologies (Core & Advanced Java, Spring Framework, Spring Boot, Hibernate, MySQL and Git). It followed a structured, week-wise curriculum combining conceptual learning, weekly assessments and project submissions, culminating in a Final Assessment Test and a project titled **"Text Search Indexer."**

**Organization:** EduSkills Academy (ISO 9001:2015 & ISO/IEC 20000-1:2018 certified) — runs the AICTE–EduSkills Virtual Internship Program under the patronage of the **AICTE National Internship Portal**, Ministry of Education.

---

## 🎯 Objectives

- Build a solid foundation in front-end technologies: HTML, CSS, Bootstrap and responsive design
- Learn JavaScript fundamentals, DOM manipulation and jQuery for interactive web pages
- Master Core and Advanced Java, including OOP, collections, JDBC, servlets and multithreading
- Develop enterprise applications using Spring Framework, Spring Boot and dependency injection
- Implement ORM-based data persistence using Hibernate and MySQL
- Manage source code using Git and GitHub with branching strategies
- Design and implement a Java-based **Text Search Indexer** covering normalization, tokenization, indexing, keyword search and term-frequency counting
- Apply the full-stack skill set learned throughout the program to a working, testable project
